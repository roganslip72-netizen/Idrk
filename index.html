TMDB API Key

StreamCheck uses the free TMDB API for movie metadata. Streaming data comes from JustWatch via the backend.

  1. Create a free account at themoviedb.org
  2. Go to Settings → API and request a Developer key
  3. Copy the API Read Access Token (long JWT starting with eyJ…)
